# papers/ — documents shown on the “Board Papers & Documents” page

Put any file here (PDF, image, Word, Excel …) and it appears on the site's **Board Papers** page automatically.

* Upload from the browser: open this folder on GitHub → **Add file → Upload files** → drag files in → **Commit changes**.
* Group files with sub-folders: `papers/2025/`, `papers/2024/`, `papers/sample-papers/`, `papers/worksheets/` — each becomes a heading.
* Name files so they read well: `2025-maths-standard-set-1.pdf` is shown as “2025 maths standard set 1”.
* Keep each file under 25 MB (GitHub's limit for browser uploads).
* Optional: add `papers/index.json` to control titles and order by hand, e.g.
  `[{"file": "2025/2025-maths-standard-set-1.pdf", "title": "CBSE 2025 · Mathematics Standard · Set 1"}]`

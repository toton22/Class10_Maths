    13.1 Where this chapter fits

    In Class IX you found the mean, median and mode of a short list of numbers. Real data — the marks of a whole school, the wages in a factory, the ages of the patients in a hospital — never come as a short list. They come packed into a grouped frequency table. This chapter teaches you to get the same three measures straight from such a table.

    The mean, the median and the mode are called measures of central tendency: each is a single number that speaks for the whole data. They answer three different questions.

    • Mean — “what is the average?”

      Add everything and divide by how many. It uses every observation. For grouped data there are three ways to compute it (Section 13.2).

    • Mode — “what is most common?”

      The value that occurs most often. For grouped data it lies inside the class with the greatest frequency (Section 13.3).

    • Median — “what is in the middle?”

      Half of the observations lie below it and half above it. To find it you need cumulative frequencies (Section 13.4).

    Mean of \(n\) observations \(=\dfrac{\text{sum of all the observations}}{n}.\)

    Median: first write the observations in ascending order. If \(n\) is odd, the median is the \(\left(\dfrac{n+1}{2}\right)\)th observation. If \(n\) is even, it is the average of the \(\left(\dfrac n2\right)\)th and the \(\left(\dfrac n2+1\right)\)th observations.

    Mode: the observation that occurs most often, that is, the one with the greatest frequency.

    The language of a grouped table

    Every question in this chapter starts from a table like “marks 10–⁠25: 2 students, 25–⁠40: 3 students, …”. Be sure of these words before you go on.

    Class interval
    one group of values, such as 40–⁠55. Its ends are the lower class limit (40) and the upper class limit (55).
    Class size \(h\)
    upper limit − lower limit. For 40–⁠55, \(h=55-40=15.\) It is also called the class width.
    Class mark \(x_i\)
    the mid-point of the class, \(\dfrac{\text{upper limit}+\text{lower limit}}{2}.\) For 40–⁠55 it is 47.5.
    Frequency \(f_i\)
    the number of observations that fall in the \(i\)th class. The total \(\sum f_i\) is the number of observations, \(n.\)
    Continuous classes
    classes that touch: 10–⁠25, 25–⁠40, 40–⁠55, … An observation equal to a common limit is counted in the higher class: a student with exactly 40 marks belongs to 40–⁠55, not to 25–⁠40.

    Statistics and Probability together form Unit VII of the syllabus, which carries 11 of the 80 marks. The questions from this chapter are predictable: a frequency table, a formula, a substitution. Nothing has to be proved and nothing has to be drawn, so a student who makes neat tables and guards the arithmetic can expect full marks here.

    Find the mean, the median and the mode of 4, 6, 6, 7, 9, 10.

    Show answer

    Mean \(=\dfrac{4+6+6+7+9+10}{6}=\dfrac{42}{6}=7.\) Here \(n=6\) is even, so the median is the average of the 3rd and 4th observations: \(\dfrac{6+7}{2}=6.5.\) The value 6 occurs twice and every other value once, so the mode is 6.

    13.2 Mean of grouped data

    The mean of grouped data is still “total ÷ number”. The one new idea is that every class is represented by a single number, its class mark. After that, the three methods — direct, assumed mean and step-deviation — differ only in how much arithmetic they cost. All three give exactly the same mean.

    Start with what you know: values with frequencies

    Suppose the observations \(x_1, x_2, \ldots, x_n\) occur with frequencies \(f_1, f_2, \ldots, f_n.\) This means \(x_1\) occurs \(f_1\) times, \(x_2\) occurs \(f_2\) times, and so on. Then

    • sum of all the observations \(=f_1x_1+f_2x_2+\cdots+f_nx_n\)
    • number of observations \(=f_1+f_2+\cdots+f_n\)
    Mean of data with frequencies
    $$\bar x=\frac{f_1x_1+f_2x_2+\cdots+f_nx_n}{f_1+f_2+\cdots+f_n}=\frac{\sum f_ix_i}{\sum f_i}$$

    \(\bar x\) is read “x bar”. The Greek capital letter \(\sum\) (sigma) means “add them all up”: \(\sum f_ix_i\) is the sum of all the products \(f_ix_i,\) with \(i\) running from 1 to \(n.\)

    Inside a class we no longer know the individual marks. So we need one number to stand for the whole class, and the natural choice is its middle.

    Definition

    The class mark (or mid-point) of a class is the average of its limits:

    $$\text{Class mark}=\frac{\text{Upper class limit}+\text{Lower class limit}}{2}$$

    For the class 10–⁠25 the class mark is \(\dfrac{10+25}{2}=17.5.\) We assume that the frequency of each class is centred at its class mark, so the class mark \(x_i\) represents every observation of the \(i\)th class.

    1. Find the class mark \(x_i\) of every class.
    2. Multiply each class mark by the frequency of its class to get \(f_ix_i.\)

    4. Divide: \(\bar x=\dfrac{\sum f_ix_i}{\sum f_i}.\)

    Why 62 and not 59.3? Both answers come from the same 30 students and the same formula. 59.3 is the exact mean, found from the actual marks. 62 is an approximate mean: in the grouped table we pretended that every student of a class scored its class mark (the mid-point assumption). Once data are grouped, the individual values are gone, so the mean found from class marks is the accepted answer.

    Method 2 — the assumed mean method

    When the \(x_i\) and \(f_i\) are large, the products \(f_ix_i\) are heavy work. We cannot touch the frequencies, but we can make the \(x_i\) smaller: subtract the same number \(a\) from every class mark, do the arithmetic with the small numbers, and add \(a\) back at the end.

    1. Choose one of the class marks as the assumed mean \(a.\) Pick one near the middle of the column — here 47.5 or 62.5. Let us take \(a=47.5.\)
    2. Find the deviation of each class mark from \(a\):  \(d_i=x_i-a=x_i-47.5.\)
    3. Multiply by the frequencies to get \(f_id_i,\) and add to get \(\sum f_id_i.\) Keep the signs.
    4. Mean \(=a+\dfrac{\sum f_id_i}{\sum f_i}.\)

    Assumed mean method
    $$\bar x=a+\frac{\sum f_id_i}{\sum f_i}$$

    \(a\) = assumed mean (any one class mark),  \(d_i=x_i-a\) = deviation of the \(i\)th class mark from \(a.\)

    Why it worksmean = assumed mean + mean of the deviations

    If \(\bar d\) is the mean of the deviations \(d_i=x_i-a,\) then \(\bar x=a+\bar d.\)

    Derivation (the book gives it — read it once and understand it)

    We subtracted \(a\) from every \(x_i,\) so to get back to \(\bar x\) we must add \(a\) to the mean of the \(d_i.\) In symbols:

    $$\begin{aligned} \bar d&=\frac{\sum f_id_i}{\sum f_i}=\frac{\sum f_i(x_i-a)}{\sum f_i}\\ &=\frac{\sum f_ix_i}{\sum f_i}-\frac{\sum f_i\,a}{\sum f_i}\\ &=\bar x-a\,\frac{\sum f_i}{\sum f_i}=\bar x-a \end{aligned}$$

    So \(\bar x=a+\bar d,\) that is, \(\bar x=a+\dfrac{\sum f_id_i}{\sum f_i}.\) Proved.

    Does the choice of \(a\) matter? No. Try every class mark of the table above as the assumed mean:

    Method 3 — the step-deviation method

    Look at the \(d_i\) column above: −30, −15, 0, 15, 30, 45. Every entry is a multiple of 15, the class size. Divide the whole column by 15 and it becomes −2, −1, 0, 1, 2, 3 — numbers you can multiply in your head. At the end multiply back by 15.

    So let \(u_i=\dfrac{x_i-a}{h},\) where \(a\) is the assumed mean and \(h\) is the class size. With \(a=47.5\) and \(h=15\):

    Step-deviation method
    $$\bar x=a+\left(\frac{\sum f_iu_i}{\sum f_i}\right)\times h$$

    \(u_i=\dfrac{x_i-a}{h},\)  \(a\) = assumed mean,  \(h\) = class size (or any common factor of all the \(d_i\)).

    Why it worksmean = a + h × (mean of the step deviations)

    If \(\bar u\) is the mean of the \(u_i=\dfrac{x_i-a}{h},\) then \(\bar x=a+h\bar u.\)

    Derivation (the book gives it — read it once and understand it)
    $$\begin{aligned} \bar u&=\frac{\sum f_iu_i}{\sum f_i}=\frac{\sum f_i\,\dfrac{(x_i-a)}{h}}{\sum f_i}\\ &=\frac1h\left[\frac{\sum f_ix_i-a\sum f_i}{\sum f_i}\right]\\ &=\frac1h\left[\frac{\sum f_ix_i}{\sum f_i}-a\,\frac{\sum f_i}{\sum f_i}\right]=\frac1h\left[\bar x-a\right] \end{aligned}$$

    So \(h\bar u=\bar x-a,\) that is, \(\bar x=a+h\bar u=a+h\left(\dfrac{\sum f_iu_i}{\sum f_i}\right).\) Proved.

    Four facts to carry with you:

    • The step-deviation method is convenient whenever all the \(d_i\) have a common factor.
    • The mean obtained by all three methods is the same.
    • The assumed mean method and the step-deviation method are only simplified forms of the direct method.
    • The formula \(\bar x=a+h\bar u\) holds even when \(a\) is not a class mark and \(h\) is not the class size: \(a\) may be any number and \(h\) any non-zero number, as long as \(u_i=\dfrac{x_i-a}{h}.\)

    The three methods are one ladder: \(x_i\;\to\;d_i=x_i-a\;\to\;u_i=\dfrac{d_i}{h}.\) Each step down makes the numbers smaller. To climb back to the mean, undo the steps in reverse order: multiply by \(h,\) then add \(a\). In the assumed mean method there was no division, so there is nothing to multiply — just add \(a.\)

    Which method should you use?

    The answer never depends on the method, so choose the one with the least arithmetic. It depends only on the size of the numbers \(x_i\) and \(f_i.\)

    Direct

    \(\bar x=\dfrac{\sum f_ix_i}{\sum f_i}\)

    Use when the \(x_i\) and \(f_i\) are small. No signs to worry about.

    Columns: class, \(f_i,\ x_i,\ f_ix_i\)

    Assumed mean

    \(\bar x=a+\dfrac{\sum f_id_i}{\sum f_i}\)

    Use when the \(x_i\) are large and the \(d_i\) have no common factor — for example when the class sizes are unequal.

    Columns: class, \(f_i,\ x_i,\ d_i,\ f_id_i\)

    Step-deviation

    \(\bar x=a+\left(\dfrac{\sum f_iu_i}{\sum f_i}\right)\times h\)

    Use when the numbers are large and all the \(d_i\) share a factor \(h.\) With equal class sizes this is the fastest method.

    Columns: class, \(f_i,\ x_i,\ u_i,\ f_iu_i\)

    13.3 Mode of grouped data

    The mode is the value that occurs most often. In a grouped table the individual values are hidden, so you first find the class with the greatest frequency — the modal class — and then a formula places the mode inside that class.

    Recall from Class IX: the mode is the observation with the maximum frequency. Sometimes two or more values share the same maximum frequency; such data are called multimodal. Grouped data can be multimodal too, but in Class X we deal only with data that have a single mode.

    NCERT Example 4mode of ungrouped data

    In 10 cricket matches a bowler took the following numbers of wickets:

    2,  6,  4,  5,  0,  2,  1,  3,  2,  3

    Find the mode of the data.

    Solution

    Make the frequency distribution table of the data:

    Number of wickets0123456
    Number of matches1132111

    The bowler took 2 wickets in the maximum number of matches (3 matches).

    Mode = 2

    Modal class and the mode formula

    In a grouped frequency distribution you cannot find the mode just by looking at the frequencies, because you cannot see the individual values. What you can see is the class that holds the most observations.

    Definition

    The modal class is the class with the maximum frequency. The mode is a value inside the modal class.

    Where inside? Look at the two neighbours. If the class before the modal class is more crowded than the class after it, the mode is pulled towards the lower end; if the class after is more crowded, the mode is pulled towards the upper end. The formula measures exactly this pull.

    Mode of grouped data
    $$\text{Mode}=l+\left(\frac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h$$

    All class sizes are assumed to be equal, and the classes must be continuous.

    \(l\)
    lower limit of the modal class
    \(h\)
    size of the class interval
    \(f_1\)
    frequency of the modal class
    \(f_0\)
    frequency of the class preceding (just before) the modal class
    \(f_2\)
    frequency of the class succeeding (just after) the modal class
    1. Check that the classes are continuous and of equal size.
    2. Find the greatest frequency. Its class is the modal class; note its lower limit \(l\) and the class size \(h.\)
    3. Write down \(f_1\) (modal class), \(f_0\) (class before) and \(f_2\) (class after).
    4. Substitute in the formula. The answer must lie inside the modal class.

    Read the mode formula in words: lower limit + (gap on the left ÷ sum of the two gaps) × width. The “gap on the left” is \(f_1-f_0,\) modal frequency minus the one before it. A big gap on the left means the crowd is on the right, so the mode moves to the right.

    Why it worksthe crossing lines behind the mode formula

    In the histogram, the two crossing lines drawn inside the modal bar meet above the mode. Similar triangles turn that picture into the formula.

    The idea (for understanding only — the book does not ask for it)

    Look at the figure “What each letter in the mode formula means”. On the left edge of the modal bar, the gap between the two tops is \(f_1-f_0\); on the right edge it is \(f_1-f_2.\) The crossing lines make two triangles standing on these two vertical gaps. The gaps are parallel, so the triangles are similar, and their heights — the distances of the crossing point from the two edges — are in the same ratio as the gaps.

    If the crossing point is at a distance \(t\) from the left edge, it is at \(h-t\) from the right edge, and

    $$\begin{aligned} \frac{t}{h-t}&=\frac{f_1-f_0}{f_1-f_2}\\ \text{so}\quad t&=\left(\frac{f_1-f_0}{(f_1-f_0)+(f_1-f_2)}\right)\times h\\ &=\left(\frac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h \end{aligned}$$

    The mode is \(l+t,\) which is the formula. In Example 6 the gaps are \(7-3=4\) and \(7-6=1,\) so the mode divides the class 40–⁠55 in the ratio 4 : 1, at \(40+\frac45\times15=52.\)

    In Example 6 the mode (52) is less than the mean (62). For other data the mode may be equal to the mean, or more than it.

    Which one do you need? It depends on the question being asked. If you want the average marks of the students, find the mean. If you want the marks obtained by most of the students, find the mode.

    The mode can also be calculated for grouped data with unequal class sizes, but that is not part of this course.

    Five slips that cost marks in mode questions:

    • Writing the greatest frequency, or the modal class, as the answer. “8” and “3–⁠5” are not the mode; the mode is the number that the formula gives (3.286).
    • Interchanging \(f_0\) and \(f_2.\) Remember: \(f_0\) comes before the modal class, \(f_2\) comes after it — the subscripts 0, 1, 2 run in the order of the table.
    • Taking \(l\) as the class mark or the upper limit. \(l\) is the lower limit of the modal class.
    • Slipping on the denominator. Compute it as \((f_1-f_0)+(f_1-f_2)\): in Example 6 that is \(4+1=5.\)
    • Using classes like 118–⁠126, 127–⁠135 as they are. First make them continuous (117.5–⁠126.5, 126.5–⁠135.5, …); then \(l\) and \(h\) change. See Section 13.5.

    If the modal class is the first class of the table, there is no class before it: take \(f_0=0.\) If it is the last class, take \(f_2=0.\)

    Check your answer in two seconds: the mode must lie inside the modal class, and nearer to the neighbour with the larger frequency. If it does not, you have mixed up \(f_0\) and \(f_2.\)

    Go back to the data you collected in Section 13.2 (marks, temperatures or heights). Find its mode, compare it with the mean, and say in one sentence what each number tells you.

Longer questions ask for the mode itself, often together with the mean or the median of the same table. In the long ones, write the modal class and the values of \(l, f_1, f_0, f_2, h\) on separate lines before you substitute — these lines carry marks even if the arithmetic slips later.

    13.4 Median of grouped data

    The median is the value of the middle-most observation: half of the data lie below it and half above it. To find “the middle” of a frequency table you must be able to count how many observations lie below any value. That running total is the cumulative frequency, and it is the key to this whole section.

    For ungrouped data, arrange the observations in ascending order. If \(n\) is odd, the median is the \(\left(\dfrac{n+1}{2}\right)\)th observation. If \(n\) is even, the median is the average of the \(\left(\dfrac n2\right)\)th and the \(\left(\dfrac n2+1\right)\)th observations.

    1. Make sure the classes are continuous. Add a cumulative frequency column (“less than” type).
    2. Find \(n=\sum f_i\) and \(\dfrac n2.\) For grouped data it is always \(\dfrac n2,\) whether \(n\) is odd or even.

    4. Note \(l,\) \(f\) and \(h\) from the median class, and cf from the class just before it.
    5. Substitute in the formula. The answer must lie inside the median class.

    Read the median formula in words: lower limit + (observations still needed ÷ observations in the class) × width. “Still needed” is \(\frac n2-\text{cf}\): the position you want, minus the number already counted before the median class.

    Five slips that cost marks in median questions:

    • Using \(\dfrac{n+1}{2}\) for grouped data. In the grouped formula it is always \(\dfrac n2.\)
    • Taking cf from the median class itself. It is the cumulative frequency of the class before the median class (22 in the worked example, not 29).

    Always look back at the table: the median you get must lie inside the median class.

    When one table asks for both the mode and the median, remember that the modal class and the median class are often different rows. The \(l\) of the mode formula and the \(l\) of the median formula are then different numbers.

    Three types cover almost every median question: (1) find the median of a grouped table; (2) the median and the total are given — find two missing frequencies \(x\) and \(y,\) as in Example 8; (3) a “less than” or “more than” table is given — first turn it into an ordinary frequency table, as in Example 7.     In type (2) you always get two equations: one from the total (\(\sum f_i=n\)) and one from the median formula. Write the first one straight away — it is an easy mark.

    Mean, median or mode — which one should you use?

    Mean

    The most frequently used measure, because it takes every observation into account and lies between the smallest and the largest value. It lets you compare distributions — for example, the average results of different schools in the same examination.

    Weakness: extreme values pull it. If a few values are very large or very small, the mean stops being a good representative.

    Median

    Best when individual values are not important and you want a typical observation — the typical productivity rate of workers, the average wage in a country. Extreme values may be present in such data, and they do not disturb the median.

    Mode

    Best when you want the most frequent value or the most popular item — the most-watched T.V. programme, the consumer item in greatest demand, the colour of vehicle used by most people.

    The empirical relationship

    Empirical relationship between the three measures
    $$3\ \text{Median}=\text{Mode}+2\ \text{Mean}$$

    “Empirical” means found by observing a great many sets of data, not proved. It holds approximately — best for data that are not too lop-sided. Given any two of the measures, it gives you the third.

    Notice the order in the pictures: the median lies between the mode and the mean, and the mean is the one dragged towards the tail. The relationship even says how far: rewrite it as \(\text{Mean}-\text{Mode}=3\,(\text{Mean}-\text{Median}),\) so the median sits one-third of the way from the mean to the mode.

    How good is it on real data? For the electricity data of Exercise 13.3, Question 1, the three measures are Median = 137, Mean = 137.05 and Mode = 135.76. Then \(3\times137=411,\) while \(135.76+2\times137.05=409.86.\) Nearly equal — but not exactly, which is what “empirical” warns you about.

    13.5 Summary

    Three measures, five formulas, one relationship — and one habit: make a neat table first. The whole chapter fits in the table below.

    To findFormula
    Mean — direct method\({\bar x=\dfrac{\sum f_ix_i}{\sum f_i}}\)
    Mean — assumed mean method\({\bar x=a+\dfrac{\sum f_id_i}{\sum f_i}}\)
    Mean — step-deviation method\({\bar x=a+\left(\dfrac{\sum f_iu_i}{\sum f_i}\right)\times h}\)
    Mode\({l+\left(\dfrac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h}\)
    Median\({l+\left(\dfrac{\frac n2-\text{cf}}{f}\right)\times h}\)
    One measure from the other two\({3\ \text{Median}=\text{Mode}+2\ \text{Mean}}\)
    • Mean: \(x_i\) is the class mark, \(d_i=x_i-a\) and \(u_i=\dfrac{x_i-a}{h}.\) All three formulas rest on one assumption: the frequency of a class is centred at its mid-point, the class mark.
    • Mode: the modal class is the class with the greatest frequency. \(l\) is its lower limit, \(h\) its size, \(f_1\) its frequency; \(f_0\) and \(f_2\) are the frequencies of the classes just before and just after it.
    • Median: the median class is the first class whose cumulative frequency is greater than \(\dfrac n2.\) \(l\) is its lower limit, \(f\) its frequency, \(h\) its size, and cf is the cumulative frequency of the class preceding it.
    • The cumulative frequency of a class is the frequency obtained by adding the frequencies of all the classes up to and including that class.
    • The mode and median formulas assume equal class sizes and continuous classes. The relationship between the three measures is empirical, so it is only approximately true.

    Before the mode or median formula: make the classes continuous

    Some tables have gaps between the classes, such as 118–⁠126, 127–⁠135, 136–⁠144, … (lengths measured to the nearest millimetre). These are called inclusive classes. The mode and median formulas assume that the classes are continuous, so close the gaps first.

    1. Find the gap: lower limit of a class − upper limit of the class before it. Here the gap is \(127-126=1.\)
    2. Take half of the gap: \(0.5.\)
    3. Subtract it from every lower limit and add it to every upper limit.
    Class as given (inclusive)Class made continuousClass mark (unchanged)
    118–⁠126117.5–⁠126.5122
    127–⁠135126.5–⁠135.5131
    136–⁠144135.5–⁠144.5140
    145–⁠153144.5–⁠153.5149
    ………

    Now \(l\) and \(h\) are read from the new classes: for 144.5–⁠153.5, \(l=144.5\) (not 145) and \(h=9\) (not 8). The frequencies and the class marks do not change — which is why, for the mean, you need not make the classes continuous at all.

    As part of their environment awareness programme, a group of students surveyed 20 houses in a locality and noted the number of plants in each house. Their data are given below. Find the mean number of plants per house.

    Number of plants0–⁠22–⁠44–⁠66–⁠88–⁠1010–⁠1212–⁠14

    Class mark \(x_i=\dfrac{\text{upper class limit}+\text{lower class limit}}{2}.\) For the class 0–⁠2 it is \(\dfrac{0+2}{2}=1,\) for 2–⁠4 it is 3, and so on.

    Exercise 13.2

    6 questions · mode of grouped data, and the mean for comparison

    The formula of this exercise — mode of grouped data
    $$\text{Mode}=l+\left(\frac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h$$

    Modal class = the class with the greatest frequency. \(l\) = lower limit of the modal class, \(h\) = class size, \(f_1\) = frequency of the modal class, \(f_0\) = frequency of the class just before it, \(f_2\) = frequency of the class just after it. The classes must be continuous and of equal size.

    A full-marks answer has four parts: (1) name the modal class and say why (greatest frequency); (2) list \(l,\ h,\ f_1,\ f_0,\ f_2\); (3) write the formula, substitute, simplify; (4) give the answer with its unit — and one sentence on what it means when the question says “interpret”.

    The mode always lies inside the modal class, and it leans towards the neighbour with the bigger frequency. In Q1 the class before (21) beats the class after (14), so the mode 36.8 sits near the lower end of 35–⁠45. If your answer falls outside the modal class, recheck \(f_0\) and \(f_2\).

    Exercise 13.3

    7 questions · median of grouped data; mean, median and mode together

    The formula of this exercise — median of grouped data
    $$\text{Median}=l+\left(\frac{\dfrac n2-\text{cf}}{f}\right)\times h$$

    Median class = the first class whose cumulative frequency is greater than \(\dfrac n2\). \(l\) = lower limit of the median class, \(n\) = number of observations \((\sum f_i)\), cf = cumulative frequency of the class just before the median class, \(f\) = frequency of the median class, \(h\) = class size. The classes must be continuous.

    The “cf” inside the formula is not the cumulative frequency of the median class. It is the cumulative frequency of the class before it — the number of observations already used up when the median class begins. Mixing these two is the most common way to lose marks in this exercise.

    The fraction \(\dfrac{\frac n2-\text{cf}}{f}\) is always between 0 and 1, so the median always lies inside the median class. If your answer falls outside it, you have picked the wrong class or the wrong cf.

    $$\begin{aligned}\text{Median}&=l+\left(\frac{\dfrac n2-\text{cf}}{f}\right)\times h\\ &=30.5+\left(\frac{50-32}{24}\right)\times10\\ &=30.5+\frac{18}{24}\times10\\ &=30.5+7.5=38\end{aligned}$$

    Mode

    The greatest frequency is 24, so the modal class is also 30.5–⁠40.5: \({l=30.5}\), \({f_1=24}\), \({f_0=18}\), \({f_2=20}\), \({h=10}\).

    $$\begin{aligned}\text{Mode}&=l+\left(\frac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h\\ &=30.5+\frac{24-18}{48-18-20}\times10\\ &=30.5+\frac{6}{10}\times10\\ &=30.5+6=36.5\end{aligned}$$

    Median = 38, Mode = 36.5

    1 for making the classes continuous (with cf) · 2 for the median · 2 for the mode.

    Statistics

    Grouped data — the basics

    • Class mark = (upper limit + lower limit) ÷ 2
    • Class size \(h\) = upper limit − lower limit
    • Every observation of a class is taken to sit at its class mark
    • Mode and median formulas need continuous classes

    Mean — three methods, one answer

    • Direct: \({\bar x=\dfrac{\Sigma f_ix_i}{\Sigma f_i}}\)
    • Assumed mean: \(d_i=x_i-a\)
    • Step-deviation: \({u_i=\dfrac{x_i-a}{h}}\) — best when \(x_i\) are large
    • All three always give the same mean

    Mode

    • Modal class = class with the greatest frequency
    • \(f_1\) modal class, \(f_0\) class before it, \(f_2\) class after it
    • The mode always lies inside the modal class

    Median

    • Make the cumulative frequency (cf) column
    • Median class: cf just greater than \({\dfrac n2}\)
    • In the formula, cf is of the class before the median class

    Cumulative tables

    • “Less than” type → the numbers are upper limits
    • “More than or equal to” type → lower limits
    • Class frequency = difference of two neighbouring cumulative frequencies

    Missing frequencies

    • Mean given → \(\Sigma f_ix_i=\bar x\times\Sigma f_i\)
    • Median (or mode) given → its class is the one that contains the given value
    • Total given → first equation: sum of frequencies = total

    Linking the three measures

    • Empirical relation: \({3\,\text{Median}=\text{Mode}+2\,\text{Mean}}\)
    • Mean: uses every observation, pulled by extreme values
    • Median: the typical value; Mode: the most popular value

    Formulas and facts to remember

    • Class mark\({x_i=\dfrac{\text{upper limit}+\text{lower limit}}{2}}\)
    • Mean — direct method\(\bar x=\dfrac{\Sigma f_ix_i}{\Sigma f_i}\)
    • Mean — assumed-mean method\(\bar x=a+\dfrac{\Sigma f_id_i}{\Sigma f_i}\), where \(d_i=x_i-a\)
    • Mean — step-deviation method\(\bar x=a+\left(\dfrac{\Sigma f_iu_i}{\Sigma f_i}\right)\times h\), where \({u_i=\dfrac{x_i-a}{h}}\)
    • Mode of grouped data\(\text{Mode}=l+\left(\dfrac{f_1-f_0}{2f_1-f_0-f_2}\right)\times h\)
    • Median of grouped data\(\text{Median}=l+\left(\dfrac{\dfrac n2-\text{cf}}{f}\right)\times h\)
    • Empirical relation\(3\,\text{Median}=\text{Mode}+2\,\text{Mean}\)
    • Mean of consecutive natural numbersThe mean of \(1, 2, 3, \ldots, n\) is \(\dfrac{n+1}{2}\).
    • Changing every observationIf each \(x\) becomes \(px+q\), the mean becomes \(p\bar x+q\).
    • Deviations from the mean\(\Sigma f_i(x_i-\bar x)=0\)

    Mistakes that cost marks

    • Putting the cumulative frequency of the median class itself in the median formula.cf belongs to the class just before the median class.
    • Choosing the class whose cf is “nearest” to \(\frac n2\), or using \(\frac{n+1}{2}\) for grouped data.Median class: the first class whose cf is greater than \(\frac n2\).
    • In a “less than” table, calling the last class the modal class because it has the biggest number.Those numbers are cumulative. Subtract first, then look for the greatest frequency.
    • Interchanging \(f_0\) and \(f_2\) in the mode formula.\(f_0\) comes before the modal class, \(f_2\) after it.
    • Using the mode or median formula on classes like 20–⁠29, 30–⁠39.Make them continuous first: 19.5–⁠29.5, 29.5–⁠39.5, …
    • Forgetting “\(\times h\)” in the step-deviation, mode or median formula.Write the formula first, then substitute letter by letter.
    • Sign mistakes while adding \(f_id_i\) or \(f_iu_i\).Add the negative products and the positive products separately, then combine.
    • With the median given and a frequency missing, hunting for the median class with \(\frac n2\).The median class is simply the class that contains the given median.

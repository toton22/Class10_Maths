Official CBSE sources

Always download question papers and marking schemes from CBSE itself — they are free.

  • Previous years' question paperscbse.gov.in — choose the year, then Class X, then Mathematics (Standard / Basic).
  • Sample Question Paper 2025-26 — StandardOfficial CBSE sample paper (PDF). The pattern this site follows.
  • Sample Question Paper 2024-25 — StandardOfficial CBSE sample paper (PDF).
  • Sample Question Paper 2023-24 — StandardOfficial CBSE sample paper (PDF).
  • CBSE AcademicLatest curriculum, sample papers with marking schemes (look under “Sample Question Paper”).
  • NCERT textbookThe Class X Mathematics book, free from ncert.nic.in.

How to use a previous-year paper

  1. Finish the chapters first, then start with the most recent year and work backwards.
  2. Three hours, no breaks, no calculator. Print the paper if you can.
  3. Mark it with the official marking scheme — step by step, not just the final answer.
  4. List every lost mark by chapter. Open that chapter's Revise tab, then redo its starred questions.
  5. Notice the repeats. After three papers you will see the same question types coming back — those are tagged “Board favourite” in every chapter's practice set here.

For Dr. PK — how to upload documents

This site is hosted on GitHub Pages, so “uploading” means adding a file to the papers folder of the site's GitHub repository. The list above then updates by itself — no code to edit.

  1. Sign in to GitHub and open the site's repository. Click the papers folder.
  2. Click Add file → Upload files, drag your PDFs in, and press Commit changes. Open the upload page →
  3. Wait about a minute for GitHub Pages to publish, then press Refresh above.
  • Name files so that they sort well and read well: 2025-maths-standard-set-1.pdf, 2025-maths-standard-marking-scheme.pdf. Hyphens become spaces in the list.
  • Make sub-folders to group files — papers/2025/, papers/2024/, papers/sample-papers/, papers/worksheets/. Each folder becomes a heading.
  • Keep each file under 25 MB (GitHub's limit for browser uploads). PDFs, images, Word and Excel files all work.
  • If the site uses a custom domain, fill in your GitHub user name and repository in assets/js/site-config.js once.
